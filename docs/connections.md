# Connection Guide

## Desde macOS

PostgreSQL:
localhost:5432

MySQL:
localhost:3306

Redis:
localhost:6379

Kafka:
localhost:29092

## Desde Docker

PostgreSQL:
postgres:5432

MySQL:
mysql:3306

Redis:
redis:6379

Kafka:
kafka:9092

## Importante

Los nombres DNS internos solo funcionan
para contenedores conectados a db-lab-network.
