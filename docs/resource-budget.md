# Resource Budget

Equipo de referencia:
macOS / 32 GB RAM / SSD.

## Política

- Ejecutar únicamente servicios necesarios.
- Mantener límites por contenedor.
- Medir con docker stats.
- Revisar memoria de Docker Desktop.
- Evitar iniciar full durante desarrollo normal.

## Presupuesto

El presupuesto Docker se debe configurar
según la carga real y dejar memoria suficiente
para macOS, IDE y herramientas de desarrollo.

Los límites de contenedor no son reservas.
