# Security

- .env nunca se versiona.
- Credenciales únicas por servicio.
- Puertos publicados solo en localhost.
- Usuarios individuales para aplicaciones.
- No utilizar root desde microservicios.
- No utilizar contraseñas de ejemplo.
- No compartir credenciales de producción.
- No exponer herramientas administrativas
  en redes públicas.
